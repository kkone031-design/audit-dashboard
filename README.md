# 심사원 월간 심사·맨데이 현황

친환경인증기관 심사원별 월간 심사 건수와 맨데이를 확인하고 **과부하 심사원**을 찾는 웹앱입니다.
서버 없이 브라우저에서만 동작하는 정적 사이트이며, 업로드한 엑셀은 외부로 전송되지 않습니다.

## 바로 열어보기 (GitHub Pages)

1. GitHub 저장소 → **Settings → Pages**
2. **Build and deployment** → Source: `Deploy from a branch`, Branch: `main` / `(root)` → Save
3. 1~2분 뒤 <https://kkone031-design.github.io/audit-dashboard/> 에서 열립니다.

로컬에서는 `index.html`을 더블클릭해도 열립니다. (엑셀 라이브러리 SheetJS 0.18.5를 CDN에서 불러오므로 인터넷 연결이 필요합니다.)

## 사용법

1. **샘플 데이터 불러오기**로 먼저 둘러보거나, **엑셀 업로드**로 실제 파일(.xlsx/.xls)을 올립니다.
   **샘플 엑셀 양식 다운로드**로 열 구성을 확인할 수 있습니다.
2. 상단에서 연도·월을 고르면 심사원별 표, 경고 요약, 달력, 추이 그래프가 갱신됩니다.
3. 표 머리글 클릭 = 정렬, 행(또는 경고 칩) 클릭 = 해당 심사원의 월간 달력과 추이 표시.
4. **현재 보기 엑셀로 내려받기** → 시트 3개: `심사원별_연-월`, `월별추이_연도`, `상세목록_연-월[_심사원]`.

### 입력 열
`심사일자, 업체명, 인증분야, 정심사원, 부심사원, 지역, 진행상태` (+ 선택: `표본어가 수`)

- 열 이름 앞뒤 공백 허용, 부심사원은 비어도 됨(여러 명은 쉼표로 구분).
- 날짜: 엑셀 날짜(일련번호), `2026-03-05`, `2026.3.5`, `2026/3/5`, `2026년 3월 5일` 모두 가능.
- 인증분야: 유기가공 / 수산가공 / 농산물 / 축산물 / 취급자 / 수산 / 무항생제
- 진행상태: 예정 / 완료 / 보류 (빈 값은 예정으로 처리). 읽을 수 없는 행은 제외하고 화면에 사유를 표시합니다.

### 맨데이 규칙
| 구분 | 맨데이 |
|---|---|
| 정심사원 — 유기가공·수산가공 | 2.5 |
| 정심사원 — 농산물·축산물·취급자·무항생제 | 2 |
| 정심사원 — 수산 | 1.5 (표본어가 5~8곳이면 3) |
| 부심사원 | 0.5 |

- 수산 표본어가: `표본어가 수` 열 값이 있으면 그 값을 사용하고, 없으면 “수산 표본어가 수동 지정” 표에서 업체별로 체크합니다.
- 진행상태 `보류`는 건수·맨데이 집계에서 제외됩니다(상단 “보류 건도 집계에 포함”으로 포함 가능). 달력에는 회색 취소선으로 표시됩니다.
- 맨데이는 심사일자가 속한 달에 합산합니다(여러 날에 걸친 심사도 시작일 기준 한 번).
- 경고: 월 맨데이 **20 초과 빨강**, **18 이상 20 이하 주황**.

규칙을 바꾸려면 `rules.js` 맨 위의 상수(`LEAD_MANDAY`, `SUB_MANDAY`, `SUISAN`, `WARN`)만 수정하세요.

## TV 현황판 (`tv.html`)
벽면 TV용 전체화면 보드입니다. 현재는 내장 샘플 데이터(기준일 2026-10-30)로 동작하는 **디자인 시안**입니다.

기본으로 **핵심 4개 화면**만 순환합니다(`?all=1`을 붙이면 8개 모두, `?slide=s2`처럼 화면 번호를 주면 그 화면만 표시).

| 번호 | 화면 | 내용 | 기본 순환 |
|---|---|---|---|
| s1 | **오늘** | 오늘 심사(업체·정/부 심사원·분야), 앞으로 7일, 심사원별 오늘의 할일(오늘 심사·지연·오늘 마감·완료). 맨데이는 카드의 작은 칩과 상단 주의 배지로만 표시 | ○ |
| s8 | **조치 필요** | 기한 초과·접수 필요·확인 지연·일정 충돌·보고서 지연·일정 누락·기한 임박을 **한 목록으로 합쳐 급한 순**으로 표시(종류마다 먼저 3건씩 보여 한 종류가 독차지하지 않음), 담당자별 조치 건수. 5개월 범위 밖의 오래된 미처리 건은 건수만 안내 | ○ |
| s7 | **5개월 인증 진행** | 이번 달 기준 2개월 전~2개월 뒤를 나란히. 달마다 신규/갱신 건수, 발급 완료/진행 중, 기한 초과·임박·접수 필요 배지, 단계 비율, 아직 끝나지 않은 건(급한 순). 진행 중인 건이 많은 달은 압축 모드, 넘치면 "외 N건". `+N일`은 접수 후 경과일 | ○ |
| s4 | **월별 부하** | 심사원 × 1~12월 표(연간 배정 기준 맨데이, 18/20 초과 강조)와 이후 달 쏠림 목록 | ○ |
| s6 | 배정 확인 대기 | 확인 대기 목록, 심사원별 미확인 건수, 확인 완료율 (내용은 s8에도 합쳐 있음) | |
| s2 | 점검 필요 | 일정 누락·미확정 / 일정 충돌 / 배정표와 다른 건 / 보고서 지연 (내용은 s8에도 합쳐 있음) | |
| s5 | 월별 인증 진행 | 1~12월 단계별 막대 + 선택한 달의 단계별 칸반. `?month=9`로 다른 달 | |
| s3 | 달력 | 이번 달 전체 일정(심사원별 색상) | |

- 20초마다 화면 전환, 데이터는 60초마다 다시 읽음. `?sec=30`(전환 간격), `?rotate=0`(전환 끄기), `?slide=1`(화면 고정), 키보드 ←/→
- 할일 데이터 열: `기한, 담당자, 할일, 업체명, 상태(대기/진행/완료)`
- 연간 배정표 열: `업체명, 인증분야, 정심사원, 부심사원, 지역, 배정월`(3 / 3월 / 2026-03 형식 가능, 배정월이 없으면 접수일·만료일의 월 사용). 연말에 확정한 이 표를 기준 명단으로 일정과 대조합니다(업체명 기준, 공백 차이 무시)
- **소속 월**: 갱신 건은 **인증 만료월**, 신규 건은 **접수월**의 현황에 들어갑니다(접수 전인 신규는 배정월). 열: `구분`(신규/갱신), `접수일`, `인증만료일`
- **기한**: 인증 만료일(갱신)과 접수일+60일(처리기한) 중 **먼저 다가오는 날**(`check.js`의 `DEADLINE.days`). 화면에는 `만료 D-12` 또는 `기한 D-12`처럼 어느 기한인지 함께 표시하고, 지나면 `만료 +17일 경과`/`기한 +12일 초과`(빨강). 7일 이내 빨강, 14일 이내 주황. 접수일·만료일이 모두 없으면 소속 월이 지났을 때 지연으로 봅니다
- **접수 후 경과일**: 건마다 `+30일`처럼 접수일부터 며칠째인지 표시(30일부터 주황, 60일부터 빨강, `DEADLINE.slow`). 단계가 앞쪽인데 경과일이 큰 건이 왜 안 끝나는지 바로 보입니다
- 갱신 건이 인증 만료 30일 이내인데 접수 전이면 "접수 필요"(`DEADLINE.renewalNotice`)
- 진행단계: 연간 배정표의 `진행단계` 열(신청전/접수/서류/현장/발급 등 표기 허용)을 사용합니다. 열이 없으면 일정으로 추정합니다(일정 없음=신청전, 예정=접수, 완료=현장심사). 단계 이름은 `check.js`의 `STAGES` 상수에서 바꿉니다.
- 점검 기준: 배정월이 지났는데 일정 없음=누락, 이번 달 배정인데 일정 없음=미확정, 같은 심사원이 같은 날 2건 이상=충돌(보류 제외)
- 데이터 연동은 `tv.js`의 `fetchRecords()`(심사 일정), `fetchTasks()`(할일), `fetchPlan()`(연간 배정표) 세 함수와 `DEMO` 값만 바꾸면 됩니다.

## 데이터 가져오기 (`import.html`, 초안)
회사의 **인증 관리 대장**(국내·해외·수산 시트)과 **놉스 일정표**(사람×날짜 달력 형태)를 올려 현황판용 자료로 바꿉니다.

1. 대장 파일을 올리면 시트별로 인증 건을 읽고, **날짜 열로 진행 단계를 판정**합니다(인증서 교부일→발급, 현장심사 날짜→현장심사, 서류 심사일→서류심사, 접수일→접수, 없으면 신청전. 오늘 이후 날짜는 아직 안 한 일로 봄). 기한은 대장의 `처리기한` 열을 우선 쓰고, 없으면 접수일+60일입니다. 종료·취하·취소 등 진행 중이 아닌 `구분`은 기본 제외(화면에서 값마다 바꿀 수 있음)
2. 놉스 파일을 올리고 연·월을 고르면 달력의 문장("현장심사_업체명(가공_갱신)")을 해석해 일정 목록으로 만듭니다. 같은 날 같은 업체는 한 건으로 합치고, 정/부는 `(정)`·`(부)`·`동행(부)` 표기로 정합니다. **표기가 없으면 알 수 없어서** "확인이 필요한 항목"에 따로 보여 줍니다. 사후관리는 기본적으로 일정에서 뺍니다(옵션)
3. 놉스의 업체명을 대장의 업체명과 맞춰(공백·(주) 등 무시, 비슷한 이름은 따로 표시) 업체명을 대장 표기로 통일합니다. 연결 못 한 업체는 목록으로 보여 줍니다
4. **'현황판에 적용'**을 누르면 `tv.html`·`my.html`이 샘플 대신 이 자료를 씁니다(`?demo=1`을 붙이면 샘플). 적용 해제로 되돌릴 수 있습니다

**중요**
- 파일은 브라우저 안에서만 처리되며, 적용한 자료는 **이 브라우저(localStorage)에만** 저장됩니다. 다른 PC·휴대폰·TV에서는 보이지 않습니다. 모두와 공유하려면 SharePoint 등 공유 저장소가 필요합니다.
- 이 저장소는 공개입니다. **대장·놉스 파일을 저장소에 올리지 마세요**(`.gitignore`가 엑셀 파일을 막아 둡니다).
- 대장 기반 자료에는 '연간 배정'이 없어서 점검 화면의 "담당 변경·월 이동"은 비교하지 않습니다. 놉스 일정이 한 달치면 그 달의 배정만 누락 여부를 판단합니다.
- 놉스 자유 문장 해석은 완전하지 않습니다(정/부 표기가 없는 일정이 많고, 분야·지역은 대장과 연결될 때만 채워짐). 맨데이는 참고용입니다.
- 열 이름·구분 값·시트 이름 규칙은 `ledger.js`·`nops.js` 맨 위 상수에 있습니다.

## 배정 확인 (`my.html` 심사원 화면 시안)
지원팀이 일정을 등록·변경하면 정·부 심사원이 각각 **'확인했습니다'**를 눌러야 확인된 것으로 봅니다. 휴대폰 화면이며 `my.html?as=김한결`처럼 열 수 있습니다.

- 확인 기한은 `ack.js` 맨 위 `ACK` 상수: 등록(변경) 후 1일 경과 **주의(주황)**, 2일 경과 **지연(빨강)**, 심사 3일 전까지 미확인이면 **긴급(빨강)**
- 등록 후 일정이 변경되면 이전 확인은 무효가 되어 **재확인**이 필요합니다(`변경일` 열)
- 일정 열에 `등록일`, `변경일`(선택)을 추가하고, 확인 기록은 `심사일자, 업체명, 확인자, 확인일시` 열을 씁니다
- 시안에서는 확인 기록이 **이 브라우저에만** 저장됩니다. 같은 브라우저에서 `tv.html`을 함께 열어 두면 확인하는 즉시 TV 숫자가 바뀝니다. 실제 운영에서는 `data.js`의 `fetchAcks()`/`saveAck()`를 SharePoint 목록 등으로 바꿔야 모두에게 공유됩니다
- **알림(Teams 등)은 아직 없습니다.** 지연이 생겨도 사람에게 자동으로 메시지가 가지는 않고, 현황판에 보이기만 합니다

## 테스트
```bash
node tests/rules.test.js
```
브라우저에서는 `tests.html`을 열면 같은 테스트가 실행됩니다. 분야별 맨데이, 수산 표본어가, 보류 제외, 날짜 파싱,
경고 경계값, 샘플 데이터의 월별 맨데이를 독립 계산과 대조합니다.

## 파일 구성
`index.html` 화면 · `tv.html/tv.css/tv.js` TV 현황판 · `tasks.js` 할일 계산 · `check.js` 배정표 대조·충돌 점검 · `ack.js` 배정 확인 · `data.js` 데이터 연동 지점 · `ledger.js` 인증 대장 읽기 · `nops.js` 놉스 달력 변환 · `import.html/import.js/import.css` 가져오기 화면 · `my.html/my.css/my.js` 심사원 화면 시안 · `style.css` 스타일 · `app.js` 화면 로직 · `rules.js` 규칙·집계 · `sample.js` 가상 샘플 · `tests/` 테스트
